# Contributing Rules

1. Generally, the author `@RVC-Boss` will reject all algorithm changes unless they fix a code-level error or warning.
2. You can contribute to other parts of this repository, such as translations and the WebUI, but please keep your changes as small as possible.
3. All changes need to be approved by `@RVC-Boss`, so your pull request may be put on hold.
4. Please accept our apologies for any inconvenience this may cause.
